# Service Mapping practice

Open index.html in a browser to practise. For hosting, publish this directory as a static site. There are no dependencies or build steps. Progress belongs to the browser profile and site address.

## Adding questions

Append an entry to the array in questions.js. Give it a unique, permanent id, the domain name, a question, four distinct options, the zero-based answer index, an explanation and a source URL. Keep existing IDs stable. New entries appear automatically in the outline and become available to returning learners, including those who finished the earlier set. Submitted choices are stored by text. For a substantially rewritten question, assign a new ID.
